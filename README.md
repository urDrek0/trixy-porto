A creative personal portfolio website for Trixy, showcasing work across web development, AI & ML, content creation, graphic design, montage, and video editing. The design is bold, vibrant, and expressive with a strong personal identity.

## ✨ Highlights

- Modern portfolio landing page with strong visual branding
- Responsive layout for desktop and mobile browsing
- Work category filtering for different creative disciplines
- Tailwind CSS-based styling for rapid custom design
- Personal profile, skill highlight, and contact section

## 🧩 Tech Stack

- HTML5
- JavaScript
- Tailwind CSS v4
- Custom assets and media from the project folder

## 📁 Project Structure

```bash
trixy-porto/
├── asset/               # Images, logos, persona, background assets
├── src/
│   ├── data.json        # Portfolio content and work items
│   ├── input.css        # Tailwind input stylesheet
│   └── output.css       # Generated CSS output
├── index.html           # Main portfolio page
├── package.json         # Scripts and dependencies
├── README.md            # Project documentation
└── package-lock.json    # Dependency lockfile
```

## 🚀 Getting Started

1. Install dependencies:

```bash
npm install
```

2. Build the CSS:

```bash
npm run build:css
```

3. Start Tailwind in watch mode during development:

```bash
npm run dev:css
```

4. Open `index.html` in a browser or use a local live preview extension.
